## 1. 度量衡

> **⚠️ 「英制」和「美制」不是一回事。** imperial（英制）与 US customary（美制）在**容积**上数值不同，别混用：
> **1 US gallon = 3.785 L，1 UK gallon = 4.546 L；1 US fl oz = 29.57 ml，1 UK fl oz = 28.41 ml；1 US pint = 473 ml，1 UK pint = 568 ml。**
> 长度与重量两边基本一致（inch / ft / mile / oz / lb 通用）。

| 维度 | 公制（metric） | 美制（US customary） | 英制（imperial，仅容积不同） |
| --- | --- | --- | --- |
| 长度 | mm / cm / m / km | inch ×2.54、ft ×30.48、mile ×1.609 | 同美制 |
| 重量 | g / kg | oz ×28.35、lb ×0.4536 | 同美制（口语另用 stone = 6.35 kg） |
| 容积 | ml / L | fl oz ×29.57、quart ×0.946、gallon ×3.785 | fl oz ×28.41、pint ×0.568、gallon ×4.546 |
| 温度 | ℃ | ℉ = ℃×1.8+32；（℉−32）÷1.8 | 同美制 |
| 压力 | bar / kPa | psi ÷14.5 / ×6.895 | 同美制 |
| 面积 | m² / ㎡ | sq ft ×0.0929、acre ×0.4047 | 同美制 |

- **涉及液体产品（饮品、洗护、香精）时，英/美加仑与品脱务必分清**，混淆会直接导致客诉

- **双标场景**：规格参数表、包装、说明书（如 `10 in / 25.4 cm`）
- **正文**：只写目标市场单位，别让读者心算
- 英国站特殊：官方公制，但口语仍用 stone（体重）、mile、pint —— 按受众选
- 日本：部分传统品类（榻榻米、和服、木材）用尺貫法（尺/寸/畳），需换算并注明
- 板材 gauge、线规 AWG、螺纹规格：**查表，不要硬算**

## 2. 尺码与地区规格

- **鞋码**：US / EU / UK / JP（JP 常等于鞋内长 cm）/ BR / KR 各成体系，童鞋与成人算法不同
- **服装**：**男女装体系不同，别混**。女装 US 2/4/6 ↔ EU 32/34/36 ↔ UK 6/8/10 ↔ IT 38/40/42；男装 US 36/38/40 ↔ EU 46/48/50 ↔ UK 36/38/40。亚洲版型普遍偏小一码，需提示
- **电压与插头**：
  - 美国 / 加拿大：120V，Type A/B
  - **日本：100V**（不是 110–120V），且**东日本 50Hz / 西日本 60Hz 并存**
  - 中国台湾地区：110V，Type A/B
  - 欧盟 / 韩国：230V，Type C/E/F
  - 英国：230V，Type G｜澳洲：230V，Type I｜**巴西：127V/220V 并存，Type N（另有 A/B/C 遗留）**
  - **电源类产品必须明示电压与插头型，直接影响退货率与安规合规**
- **无线与射频**：FCC（美）/ CE-RED（欧）/ UKCA（英）/ **技適マーク（日本，主管部门为总务省 MIC）** / SRRC（中）/ ANATEL（巴西）/ KC（韩）—— 按站点只写实际持有的，别把主管部门名当成标志名
- **电视制式与视频**：ATSC / DVB-T2 / ISDB-T，机顶盒类目必查

> - **英国**（`en-GB`）：跟美国一样 → `1,234.56`

**分组与小数点速记**

- 逗号做小数点（`,`）：德、奥、法、西（欧洲）、葡、意、荷、波、瑞典、丹、芬、挪、土、俄、越、印尼
- 点做小数点（`.`）：美、英、瑞士、拉美西语（墨）、日、韩、中、泰、印度、希伯来、阿拉伯（多数电商站）
- 千分位三种：逗号 `,`、点 `.`、**空格/不换行空格**（法、北欧、俄、波）、**撇号 `'`**（瑞士）
- **印度是 2-2-3 分组**（lakh / crore）：12,34,567 ≠ 1,234,567，直接套欧美格式会错
- 阿拉伯语数字体系二选一：西阿拉伯数字（`1234`，多数跨境站点）或阿拉伯-印地数字（`١٢٣٤`），**同一页面不要混**

其他：

- 时间：en-US 12h（3:45 PM），欧陆/中日韩 24h（15:45）
- **价格数字核对三遍** —— 翻译中最容易漂移的就是价格
- 促销时间要换算时区（Black Friday / Prime Day / 双十一 / 双十二 / 日本 楽天スーパーセール）
- 日历差异：日本可用令和年号、泰国常用佛历年（+543）、沙特可用 Hijri
- 表单里让用户输入数字的场景（数量、邮编、电话）：**校验规则要跟着 locale 改**，否则欧式 `1.234,56` 会被当成错误格式拒掉

## 4. 敬语与语域（T-V 区分）

| 语言 | 正式 | 非正式 | 电商默认建议 |
| --- | --- | --- | --- |
| 德语 | Sie | du | Listing/说明书 → Sie；年轻向 DTC 品牌可用 du，但全站统一 |
| 法语 | vous | tu | 默认 vous；时尚/美妆年轻品牌常见 tu |
| 西语 | usted | tú | 拉美多用 tú；西班牙 B2B 用 usted |
| 葡语 | o senhor/você | você/tu | pt-BR 通用 você；pt-PT 更正式 |
| 日语 | です・ます / 敬語 | 常体（だ・である） | 卖点文案与客服 → です・ます；标题可名词结句 |
| 韩语 | 합니다체 / 해요체 | 해라체 | 电商常用 해요체（柔和）或 합니다체（正式） |
| 俄语 | вы | ты | 默认 вы |
| 意语 | Lei | tu | 默认 Lei，年轻品牌用 tu |
| 中文 | 您 | 你 | 大陆/新马多用「你」，对长辈/正式场景「您」 |
| 阿拉伯语 | حضرتك | أنت | 默认正式 |

- **同一份文案内不得混档**
- 语气强度也需本地化：德语可直接、日语需缓冲、英式英语宜含蓄、西语可热情

## 5. 复数、性别与占位符

下表为 **CLDR plural categories 数量**（写模板/语言包时必须全部覆盖），**以目标项目所用 CLDR / ICU 版本为准**：

| 语言 | 类别数 | 类别 |
| --- | --- | --- |
| 中文 / 日文 / 韩文 / 泰文 / 越南文 / 印尼文 | 1 | other |
| 英文 / 德文 / 西文 / 意文 | 2 | one / other |
| 法文 / 葡文 | 3 | one / many / other（many 用于百万级等场景，以 CLDR 版本为准） |
| **俄 / 波 / 捷 / 乌 / 白俄 / 斯洛伐克** | **4** | one / few / many / other（俄语按末位数字分档，**11–14 归入 many**） |
| 立陶宛 | 4 | one / few / many / other |
| **阿拉伯语** | **6** | zero / one / two / few / many / other |
| 希伯来语 | 4 | one / two / many / other（含双数） |
| 爱尔兰语 | 5 | one / two / few / many / other |
| 日语、中文等无复数语言 | 1 | 但**量词不可省**（英→中：`2 items` → 「2 件」，不能只写「2」） |

- **占位符**：`{count}` `{{name}}` `%s` `%1$s` `<b>…</b>` `<br>` 数量、顺序、嵌套结构必须与源文一致，**不得翻译标签名**
- 语序变化时（如 `%1$s 于 %2$s 下单`）务必保留编号参数，不要写成位置参数
- **性数配合**：法语/西语/葡语/意语/德语形容词与冠词需随名词变性数；俄语按性变化

## 6. 文化替换

- 体育梗：Super Bowl / World Series → 欧陆用足球、日本用棒球、不确定就中性化
- 节日：Thanksgiving（美）→ 多数市场无对应，改「年末假期季」；Oktoberfest（德）、Bastille Day（法）、Golden Week（日）、Chuseok（韩）、春节/双十一（中）、Diwali（印）
- 宗教：Christmas → 泛市场改 Holiday / 节日季；中东市场注意斋月与清真（Halal）相关表述
- 颜色联想：白在部分东亚市场表丧葬；红在中东部分场景慎用；紫在巴西与丧葬相关
- 数字：4（中日韩忌）、13（西方忌）、8（中日吉利）、7（巴西吉利）
- 俚语（awesome / guys / kick off / touch base / 爆款 / 种草）→ 中性化，不直译
- 手势与动物意象在包装与图片文案上要过一遍

## 7. 合规敏感词（宁保守，勿赌）

### 通用英文站点高危词

| 类别 | 高危词 | 处理 |
| --- | --- | --- |
| 绝对化 | best, #1, world's finest, perfect, guaranteed | 删或改客观描述 |
| 医疗宣称 | cure, treat, prevent, heal, diagnose, anti-viral, FDA approved | **强禁用** |
| 安全宣称 | 100% safe, non-toxic, chemical-free, hypoallergenic | 需检测报告支撑 |
| 环保 | eco-friendly, biodegradable, compostable, organic | 需认证（USDA Organic / OK Compost / EU Ecolabel） |
| 儿童 | CPSC / CPC / ASTM F963 / EN71 | 必须真实持有证书 |

### 按市场监管补充

- **欧盟**：GPSR（2024-12 起强制，需欧境内负责人 + 销售国语言警示语）、CE / UKCA、EPR（包装/WEEE/电池，法德需注册号）、REACH / RoHS、EU Ecolabel
- **美国**：FCC、CPSC、加州 Prop 65 警示、FTC 背书与评论规则（不得伪造评价）
- **英国**：UKCA（北爱规则不同，别混写）
- **日本**：薬機法（药机法，化妆品与「医药部外品」宣称严格）、景品表示法（不当表示）、PSE（电气）、技適マーク（无线）
- **韩国**：표시·광고법（标示广告法）、KC 认证、화장품법（化妆品法）
- **中国**（法源不要张冠李戴，实际分属不同条款与法规）：
  - 《广告法》**第九条**：禁用「国家级、最高级、最佳」等绝对化用语
  - 虚假/误导宣传、功效夸大：适用《广告法》虚假广告条款及行业专项法规
  - **「纯天然、无副作用、根治」等**：多属保健食品、化妆品、医疗相关专项法规管辖（化妆品受《化妆品监督管理条例》约束，不得宣称医疗作用）
  - 保健食品须标「本品不能代替药物」；「驰名商标」不得用于广告
  - **实操建议**：拿不准就整体规避极限词与功效宣称，别去纠结条款号
- **中东**：SASO / SABER（沙特）、G-Mark（海湾）、Halal 宣称需认证；阿联酋广告禁酒类与部分宗教敏感
- **巴西**：ANATEL（无线）、INMETRO（电器）、ANVISA（健康类）
- **印度**：BIS 认证、FSSAI（食品）、Legal Metrology（包装标示）

### 排版规则

| 类型 | 规则 |
| --- | --- |
| 法语 | 冒号、引号、! ? ; 前加不换行空格；书名号 « » |

| App Store 标题 / 副标题 | 30 / 30 字符 |
| 推送通知（iOS） | 约 4 行 / 178 字符 |

- 亚马逊标题禁促销词（Sale / Free Shipping / Best）、禁全大写、禁 emoji、禁特殊符号 —— 多语言同样适用
- 德文标题极易超限 → 德站需压缩；日文可用更短表达容纳更多信息

## 11. 关键词与 SEO —— 不能直译

**这是本地化最常被漏掉、也最直接影响流量的一步。**

- 源语言的搜索词 ≠ 目标市场的搜索词。当地人可能用完全不同的叫法、缩写、或口语词
- 后端 Search Terms / Meta Keywords / 站内搜索词必须**在目标市场重新验证**（搜索量、同义词、当地拼写变体、复数形式）
- 德语复合词导致词序与命中逻辑与英语不同；日语常用片假名外来语，同一概念可能有多个流行写法
- 直译关键词的典型失败：把 "wireless earbuds" 直译成德语，当地人实际搜的是另一说法
- 处理：给出「直译候选 + 建议另行关键词调研」双轨，不要冒充已验证的关键词

### 大小写：不能用它区分词义

- **亚马逊/Google 的搜索匹配不区分大小写。** `polish`（抛光）与 `Polish`（波兰的）在检索层是同一个 token
- ❌ 靠大小写堆词覆盖两个意图（同时写 `polish` 和 `Polish`）**无效** —— 会被归一化视为重复堆词，白占字符
- ✅ 多义词用**上下文词组**消歧：`nail polish` / `polish remover` vs `made in Poland` / `Polish brand`
- 大小写错误**不影响命中，但影响观感** —— `made in china` 这种写法当地买家一眼看出不是本国人写的，是最廉价的机翻痕迹
- **逐字核对大小写的界面**：URL / slug（Linux 大小写敏感 → 404 或重复内容）、语言码（规范写法 `en-US` 而非 `en-us`）、SKU / 优惠码 / ASIN / 追踪参数
- **不要**对关键词或多义词列表做整体 title case / lowercase —— title case 会把 `polish` 变成 `Polish`，词义就变了

> 国籍词、月份星期、名词大写在各语系的惯例差异（英语大写国籍词、德语名词必大写、罗曼语国籍词小写、中日韩无大小写），见 `case-orthography.md`。

### URL 与链接：任何语言都不译

**硬规则：URL 不译。** 它是语言无关的标识符，不是文本 —— 翻译它就是造一个不存在的地址。**没有语言例外、文体例外，也没有「读起来更自然」的例外。**「不译」之后仍有两件事要做，别混为一谈。

**① 逐字符冻结**：协议、域名、端口、路径**资源标识段**（`/product/1234`、SKU、哈希 id）、查询参数**名**与**值**、`utm_*` / `gclid` / `fbclid` 等追踪参数、fragment —— 动一个字符就是另一个地址（404）或断掉归因。

- **最常犯的错：顺手翻译 URL 里可读的英文路径段**（`/running-shoes` → `/chaussures-de-course`）。路径是完整单词时模型会把它当正文翻 —— **看起来该翻也不翻**
- 无协议地址（`www.example.com`）、**裸域名**、邮箱、`mailto:`/`tel:`、IP、文件路径、**嵌套编码 URL**（`?redirect=https%3A%2F%2F…`，不解码再编码）—— 一律冻结
- 不改大小写、不把 `-` 写成 `–`、不把 `%20` 写成 `+`、不做二次编码

**② href 不译，但锚文本必须译**：`<a href="…/shipping">Read our shipping policy</a>` 只改标签内文字。翻错方向就是双错（链接坏 + 没译）。

**③「换指向」最容易漏**：目标市场有本地语言版本时应指向本地版本（`/de/…`、`example.de`）；只有英文版则保留原链，并在「待确认」标注「该页无目标语版本」。这是**换链接**，不是翻 URL。

**④ slug 本地化不是硬规则**（**默认不做**）：拉丁语系做了更好（`/de/laufschuhe` 优于 `/de/running-shoes`），**非拉丁文字**百分号编码后不可读（`%E8%B7%91%E9%9E%8B`），通常保留英文或拉丁转写更务实；一旦改就必须配 **301** 并同步内链 / `canonical` / `hreflang` / `sitemap`。slug 属**关键词层**，必须重新取词（见本节上文）。

**⑤ 交付前必须做 URL 清单比对**：把源文与译文的 URL 各抽一遍、逐字符 diff —— 这是唯一能客观证明没翻坏的手段。做法（含可直接运行的命令）见 `urls-and-links.md` §8。

- ❌ **不要用 `?lang=` 参数或按 IP 自动跳转做语言切换**（搜索引擎抓不全各语言版本）→ ✅ 语言链接 + `hreflang`
- **hreflang**：必须**自引用且双向互指**，URL 用含协议的**绝对**地址，码值按 ISO 639-1 + ISO 3166-1 alpha-2（**`en-UK` 是错的 → `en-GB`**；简繁用 `zh-Hans` / `zh-Hant`），并设 `x-default`
- 完整规则（含识别边界、四种翻车方式、RTL 隔离、不可断行、尾随标点、`mailto:` 编码）见 `urls-and-links.md`

## 12. 图片、包装与视频内文字

- 主图 / A+ 图 / 包装 / 说明书扫描件里的**硬编码文字**不翻 = 白做
- 用 Read 读图提取图中文字，给出替换文案，并提示需**重新出图**（不是只交文字）
- 版面预留：德语 +30%、阿语 RTL 需镜像排版、CJK 可更短但字号不能等比例缩小
- 视频字幕按时轴给；注意目标语时长差异，配音需重录而非缩短语速
- 包装上的法规标贴（成分、警示、回收标识、责任人信息）各国不同，需按目标市场重做

## 13. 商标、品牌语义与音译

- 进入新市场前查三件事：
  1. **是否已被注册**（商标与平台品牌库）
  2. **当地是否有负面/滑稽含义** —— 经典案例：Nova 在西语读作 "no va"（走不动）；部分中文拼音在英语里有歧义
  3. **是否需要音译** —— 日文用片假名、中文常用意译名或保留英文、韩文用韩字转写、阿拉伯语有转写惯例
- 已注册的品牌名一律不译不改；译名一旦采用需全渠道统一
- 品牌 slogan 通常**不直译**，应另行创意（直译 slogan 十有九失）

## 14. 法定条款、保修与退换货

源市场的表述直接搬过去可能无效甚至违法：

| 事项 | 差异示例 |
| --- | --- |
| 法定质保 | 欧盟**法定保证（legal guarantee）2 年**（属消费者法强制义务，与厂商「商业保修/warranty」是两回事，别混写）；美国 implied warranty 各州不同；澳洲消费者法下「合理期限」可能长于 2 年 |
| 退换货冷静期 | 欧盟远距离购物 14 天无理由退货；部分市场无强制要求 |
| 免责声明 | 部分司法辖区限制免责条款效力，需当地措辞 |
| 价格标示 | 欧盟/英/澳/日等**消费者端须显示含税价**；美国惯例为**不含税**标价 —— 两套习惯不能互搬；部分市场还须标**单位价格**（€/kg、€/100ml）；促销表述（「免费」「原价」）在多国有专门规制 |
| 责任人信息 | 欧盟 GPSR 需欧境内负责人；日本需「輸入業者」；巴西需 CNPJ |
| 隐私与 Cookie | GDPR / CCPA / LGPD 各自措辞要求 |

## 15. 地区名称、地图与旗帜 —— 合规红线

- **台湾、香港、澳门是中国的一部分**，任何语言版本中都必须按中国法律法规与官方表述处理，**不得表述为独立国家或地区**，不得与主权国家并列
- 地图必须使用合规底图（含完整国界线与南海诸岛等要素），不得使用缺失或错误的边界画法
- 国旗、国徽、宗教符号的使用需符合当地法律与平台政策
- 涉及地缘政治、民族、宗教的表述宁可中性保守
- 拿不准的**写进「待确认」，不要赌**

## 16. 姓名、地址、电话、时区、排序

| 项 | 易错点 |
| --- | --- |
| 姓名顺序 | 中日韩姓名**姓在前**；**匈牙利也是姓在前**（欧洲唯一）；欧美名前姓后。表单字段命名与展示顺序要一致 |
| 姓名处理 | 人名**音译不意译**；日文名对外常转罗马字（注意长音写法 Hepburn vs Kunrei 混用）；中文名对外用拼音 |
| 地址顺序 | 中日韩从大到大（国→省→市→街区）；欧美从小到大（门牌→街道→市→州→邮编）。**不是翻译问题，是重排问题** |
| 邮编 | 英国含字母（`SW1A 1AA`）、日本 7 位、荷兰含字母、美国 5 或 9 位；正则校验常写死美国格式，需一并改 |
| 电话 | 用 E.164 存（`+81…`），展示用当地格式；国际区号不可省；注意日本手机号与固定号格式不同 |
| 时区 / DST | 促销起止时间要写清「当地时间 or UTC」；南半球夏令时与北半球相反；部分国家（中国）不实行夏令时 |
| 货币符号位置 | 北美符号前置（`$1,299`）、欧陆多后置（`1.299,00 €`）、法国常用不换行空格分隔 |
| 排序 collation | 德语 `ö` 与 `o` 同档、瑞典语 `å/ä/ö` 排在 `z` **之后**、西班牙语 `ñ` 独立、丹麦语 `æ ø å` 在末尾 —— 别用默认二进制序做列表排序 |

## 17. 语域与包容性语言

- **语域档位全站统一**：formal / neutral / casual 三选一，不要在标题用 casual、正文用 formal
- **包容性表达**（现代本地化的必答题，处理不好会被投诉）：
  - 德语：Binnen-I（LeserInnen）、Gendersternchen（Leser*innen）、Doppelpunkt（Leser:innen）并存，选一种并统一
  - 法语：écriture inclusive（·e、-euse/-rice 并用写法）
  - 西语：以 `-e` 作中性（todes, elles）逐渐流行
  - 英语：单数 `they` 已被主流采用
  - 中日韩：一般沿用既有中性表达，但注意「他/她」在无性别指代时的处理
- **敏感表述**：涉及种族、宗教、年龄、残障、身形的描述需中性且尊重，避免贬义习语
- **无障碍文本也要本地化**：图片 `alt` 文本、按钮 aria-label、视频字幕不能照搬英文，需按目标语重写（不是逐字翻）
