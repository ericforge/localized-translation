# 表面形式层：标点、符号与书写系统

> 这一层的特点是：**不改变「说了什么」，只决定「像不像母语者写的」**。机翻基本不管，自评也看不出，只有对照目标语的排版规范才能发现。
>
> 与另两份文件的分工：**大小写改词义** → `case-orthography.md`；**符号用错** → 本篇；**数学正确但当地不这么用** → 本篇 §4 + `localization-checklist.md`。

## 1. 标点：同一功能，各语系符号不同

| 功能 | 英语 en | 中文 zh | 日语 ja | 德语 de | 法语 fr | 西语 es |
| --- | --- | --- | --- | --- | --- | --- |
| 双引号 | `"…"` | `“…”`（港台常用 `「」`） | `「」`（内层 `『』`） | `„…“`（瑞士德语常见 `«…»`） | `« … »` | `«…»` 或 `“…”` |
| 单引号 | `'…'` | `‘…’` | `『』` | `‚…'` | `‹ … ›` | `‘…’` |
| 书名号 | *斜体* 或引号 | `《》`（内层 `〈〉`） | `『』` 或 `「」` | *斜体* | *斜体* 或 `« »` | *斜体* 或 `«»` |
| 破折号 | `—`（美式无空格）／`–` 带空格（英式） | `——`（**占两个字符位**） | `—` 或 `——` | `–`（带空格，Gedankenstrich） | `—`（带空格） | `—`（对话用，带空格） |
| 省略号 | `…` 或 `...` | `……`（**必须六点**，占两位） | `……` 或 `…` | `…` | `…` | `…` |
| 并列分隔 | 逗号 + `and` | **顿号 `、`** | `、` | 逗号 | 逗号 | 逗号 |
| 问号/感叹号 | `?` `!` | `？` `！`（全角） | `？` `！` | `?` `!` | `?` `!` | **`¿…?`** **`¡…!`**（句首也要标） |

高频错误：

- **中文用三个点当省略号**（`...`）—— 应为 `……`
- **中文破折号只写一个 `—`** —— 应为 `——`
- **德语引号写成英语 `"…"`** —— 应为 `„…"`（瑞士用 `«…»`）
- **法语漏掉 `« »` 内的空格**（见 §2）
- **西语只写句末问号** —— `¿` `¡` 必须成对
- **把中文 `《》` 搬进英文文案** —— 英文用斜体或引号
- **在中文里用英文逗号分隔并列词** —— 中文有顿号，用逗号读起来是「分句」不是「并列」

## 2. 不可断空格（non-breaking space）

漏掉不是「错字」，是**换行时符号跑到行首**，一眼就能看出没做过母语校对。

| 位置 | 例子 |
| --- | --- |
| 法语 `; : ! ?` 与 `« »` 前后 | `Bonjour !`、`« texte »`（现代排版用窄不可断空格 U+202F，传统用 U+00A0，按风格指南定） |
| 数字与单位之间 | `10 km`、`220 V`、`500 ml`（SI 规范要求不可断） |
| 货币符号与金额之间（部分语言） | 法/西的习惯 |
| 姓名缩写与姓之间 | `M. Dupont`、`Dr. Weber` |
| 章节号与数字之间 | `§ 3`、`No. 5` |

**中文正文中的汉字单位通常不加空格**：`10公里`、`第3章`。但 SI 符号、英文缩写、技术参数和中英混排可能需要空格；应按项目技术写作规范区分，不要一概禁止。

### ⚠️ 边界：不可断空格是「正文排版规则」，不能施于标识符

这是本文件与 `urls-and-links.md` 的**交叉点，也是最容易两条规则打架的地方** —— 法语的「`:` 前加不可断空格」若被机械执行，会把地址弄坏。

| 不要加空格的对象 | 误加会怎样 |
| --- | --- |
| URL 里的 `:` 与 `/`（`https://example.com`） | 链接打不开 |
| **`IP:端口` 的冒号**（`192.0.2.1:8080`、`[2001:db8::1]:443`） | 地址失效 —— **法语规则不适用于 IP 与端口** |
| IPv6 内部的冒号（`2001:db8::1`） | 直接失效 |
| 文件名、路径、代码、命令行、SKU、订单号 | 复制即失败 |

**判据：区分该字符是「标点」还是「标识符的一部分」。** 属于标识符的一部分 → **一个空格都不加**，也不做任何本地化「规范化」。见 `urls-and-links.md` §0.4。

## 3. 连字符三级 —— 别混用

| 符号 | 码位 | 用途 | 例子 |
| --- | --- | --- | --- |
| hyphen | `-` U+2010（ASCII `-` U+002D 通用） | 复合词、拆行 | `state-of-the-art` |
| en dash | `–` U+2013 | **范围、区间、连接** | `10–20 cm`、`2020–2025`、`Paris–London` |
| em dash | `—` U+2014 | **插入语**（见 §1） | — |
| minus | `−` U+2212 | **数学负号** | `−5 °C` |

范围号写成 `10-20` 用 hyphen 是随处可见的错；温度负数用 hyphen 会与范围号混淆。这三者在**技术文档与产品参数**里是硬要求。

## 4. 书写系统层：字体与码位不等于语言

### 4.1 汉字字形（Han unification）

**同一个 Unicode 码位，在中文字体与日文字体下字形是不同的。** 典型字：`骨`、`直`、`真`、`令`、`每`、`与`。

- 日文页面若用中文字体渲染，日文读者会觉得「字长得不对」—— 这是**技术上的国别判断错误**，比用词错误更根本
- 落地做法：`<html lang="ja">` / `lang="zh-Hans"` + **按语言指定 font-family 回退链**，不要一个全局字体吃所有语言
- 同理，简体与繁体各有自己的字形标准（大陆 / 台湾 / 香港字形不同）

### 4.2 简体→繁体不是换个字形就完事

**简繁转换工具只换字形，不换词汇**，会产出「繁体字写着大陆词」的尴尬文本：

| 大陆（zh-CN） | 台湾（zh-TW） | 说明 |
| --- | --- | --- |
| 软件 | 軟體 | 词汇本身不同 |
| 质量 | 品質 | |
| 信息 | 資訊 | |
| 土豆 | 馬鈴薯 | 台湾「土豆」指花生 |
| 激光 | 雷射 | |
| 项目 | 專案 | |

**必须人工过一遍词汇**，不能只靠转换器。

### 4.3 数字体系

| 语系 | 数字 | 使用地区 |
| --- | --- | --- |
| 西阿拉伯数字 | `0123456789` | 全球多数，含马格里布（摩洛哥/阿尔及利亚/突尼斯） |
| **东阿拉伯数字** | `٠١٢٣٤٥٦٧٨٩` | 埃及、海湾、伊拉克、约旦等多数中东国家 |
| **波斯数字** | `۰۱۲۳۴۵۶۷۸۹` | 伊朗（与阿拉伯数字是不同的码位） |

**同一品牌的阿语站点，不同国家可能要求不同数字体系** —— 拿到阿语稿要确认用哪套，不要默认 0-9。

### 4.4 组合字符与 Unicode 规范化

越南语声调、韩文谚文、泰文与天城文的元音声调都是**组合字符**，同一串文字可以有两种合法编码（NFC 预组合 / NFD 分解）：

- **后果**：看起来完全一样的两串字，程序比较时**不相等** → 站内搜索、SKU 去重、术语匹配静默失败
- 落地：入库前统一 **NFC**；比较前先 normalize；不要按字符个数切割（会拆散字形簇）
- 韩文同理（谚文音节 vs 单个字母）；泰国/天城文还要处理「字符簇不可切分」

### 4.5 阿拉伯语与希伯来语

- 阿拉伯字母有**首 / 中 / 尾 / 独立**四种连字形态，同一字母依位置变字形 —— 不要按「一个字母一个码位」做长度或截断
- **短元音（变音符）通常省略**：省略是正常的，补齐反而生硬；但也意味着同名歧义更多
- 希伯来语同理，元音符号（niqqud）一般省略

## 5. 「惯例正确」≠「数学正确」

换算不能只算数学，要跟**当地实际使用惯例**：

| 场景 | 数学值 | 当地惯例 | 该写哪个 |
| --- | --- | --- | --- |
| 烤箱温度 | 350 °F = 177 °C | 英/欧食谱写 **180 °C**（风扇烤箱常写 160 °C），另有 gas mark | 写着 180 °C —— 写 177 °C 反而像机器算的 |
| 纸张尺寸 | — | 美加用 Letter，其余用 **A4** | 按市场切换（说明书与打印模板） |
| 服装尺码 | — | 各国体系不同 | 见 `localization-checklist.md` 尺码节 |
| 电压 | — | 100/110/220–240 V + 频率 | 见 `localization-checklist.md` |
| 年度周次 | — | ISO 8601 周编号（周一为首日）vs 美式（周日起） | 排期与促销表要注明用哪套 |
| 「两周」 | 14 天 | 英式 fortnight；德语 14 Tage；日文 2週間 | 按语言选惯用表达 |
| 财年 | — | 日本 4 月起、美国 10 月起、印度 4 月起 | 涉及预算/财年表述时核对 |

## 6. 视觉与文化符号

- **洗涤标识**：ISO 3758 符号体系 —— 符号本身**不译**，但顺序与含义固定，改图即改义
- **emoji**：`👍`、`OK` 手势在部分中东与西非、巴西/土耳其有冒犯义；`🙏` 语义跨文化差异大 —— 营销文案里慎用，宁可不用
- **颜色**：白色在中日韩印为丧色；红色在中国为喜庆、在西方为危险；绿色在伊斯兰文化具神圣含义
- **数字禁忌**：4（中日韩）、13（西方）；楼层与房号常跳过
- **旗帜 / 地区表述**：`zh-TW` / `zh-HK` 只能作语言代码，不得进「国家」下拉框，不得用旗帜 emoji 指代台湾地区（详见 SKILL.md「翻译之外 7 件事」第 7 条）
- **图标方向**：RTL 语言下按组件定义方向性；箭头、返回、时间轴等通常需要检查镜像，但品牌标识、数字、地图和媒体控件不能机械翻转

## 7. 自检

- [ ] 中文并列词用顿号 `、`，不是英文逗号
- [ ] 连字符三级未混用（范围用 en dash、数学负号用 minus）
- [ ] 不可断空格已处理（法语标点、数字与单位之间）

- [ ] 中日韩页面按语言指定了字体回退链，未被单一字体的汉字字形串台
- [ ] 简繁转换后**已人工核对词汇**（不只是字形）
