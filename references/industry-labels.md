# 受管制品类标签、官方语言要求、中文市场场景

> **本文档只做「提示与定位」用途，不构成合规意见。** 具体条款号与限值会变动，**执行前必须核对官方现行文本或咨询当地合规顾问**。凡拿不准的，写进「待确认」，不要赌。

本文件覆盖三块，都是「文字翻译对了但仍会被下架」的层面：

- A. 销售国**官方语言强制**要求
- B. 受管制品类的**强制标签内容**
- C. **中文市场与「外→中」**场景

---

## A. 销售国官方语言强制（P0，最容易整批卡关）

| 市场 | 要求 | 后果 |
| --- | --- | --- |
| 法国 | **Loi Toubon**：面向法国消费者的商品说明、使用说明、广告需有法语版本 | 无合法法语版本可被要求下架/罚款 |
| 加拿大 | 联邦**英法双语**要求（标签与说明）；**魁北克 Bill 96** 进一步强化法语显著性与优先性 | 英语单语版本不合规 |
| 瑞士 | 德语/法语/意大利语按销售区域 | 视渠道 |
| 德国 / 奥地利 | 说明书与安全提示需德语 | 下架风险 |
| 意大利 / 西班牙 / 荷兰 / 波兰 / 北欧 | 一般要求销售国官方语言的使用说明 | 下架风险 |
| 沙特 / 阿联酋 / 埃及 | 标签与说明需**阿拉伯语**（常要求与英语并列） | 清关扣货 |
| 韩国 | 标签与说明需**韩语** | 下架 |
| 日本 | 标签与说明需**日语**；无线电需技適マーク | 下架 |
| 巴西 | 葡语；说明书与标签需本地化 | 清关 |
| 中国 | 境内销售商品标签与说明需**中文**；进口商品需符合中文标签规定 | 清关/下架 |

**操作规则**

1. 一句话结论：**「这产品要卖到哪个国家」决定了必须交付哪些语言的版本，而不是客户想要什么语言。**
2. 服务商说「只翻英语」时，主动提示上述强制要求。
3. 无法确认时，把「需目标国官方语言版本」写进「待确认」。

## B. 受管制品类的强制标签内容

### 食品 / 饮料（欧盟为代表）

- 过敏原**必须**突出标示（EU 14 类过敏原）
- 营养声明表格式与单位有法定排版要求
- 净含量、保质期（best before / use by）、储存条件、生产商/进口商名称地址
- 成分表需按**含量降序**；配料名用当地法定名称
- **不属翻译范畴但必须提示**：这些内容的版式与内容需按目标市场重做，不只是把字翻过去

### 化妆品 / 个护

- **INCI 成分名不翻译** —— 国际命名，全套语言版本里保持拉丁原名
- 功效宣称受严格管制：「美白」「抗皱」「修复」等在中/日/韩/欧各有分级与禁用语
- 需标示：责任人名称地址、批号、开封后使用期（PAO）、注意事项
- 中文场景：《化妆品监督管理条例》下**不得宣称医疗作用**，特殊化妆品需注册

### 纺织品 / 服装 / 鞋类

- 纤维成分标示（含量百分比）为强制项，需按目标市场格式
- 洗护符号（洗涤、漂白、干燥、熨烫）为国际化符号，**图形不翻译**
- 欧盟对鞋类材质（鞋面/内里/鞋底）有标示要求
- 原产地标示

### 电子产品 / 电器

- 认证标志（CE / UKCA / FCC / 技適 / KC / PSE / CCC / ANATEL / NOM 等）**按实际持有的写，不得虚构**
- 电压、频率、插头型（见 `localization-checklist.md` §2）
- 电池与电子废弃物的回收标识（WEEE 打叉垃圾桶、电池标识）
- 说明书中的安全警告不得删减

### 化学品 / 清洁剂 / 胶粘剂

- **CLP 法规**（欧盟）：危害象形图、信号词（Danger / Warning）、H/P 危险与防范说明句，均有法定措辞
- 这类文本**不能自由改写**，须用法规规定的标准语句；翻译质量取决于是否用了合规句式

### 儿童用品 / 玩具

- 年龄警示、成人监护提示、小零件窒息风险
- 欧盟 EN71、美国 ASTM F963 / CPSIA（儿童产品证书 CPC）
- 年龄分级表述按当地法规口径，不可自行降低

### 原产地与供应链溯源

- **美国 19 CFR 134**：进口商品需标示原产国
- **UFLPA**（维吾尔强迫劳动预防法）：涉及供应链溯源，表述需谨慎
- 原产地标示一旦写错属实质性违规，列为「待确认」高位项

## C. 中文市场与「外→中」场景

这份 skill 默认是「出海」视角，但反方向同样常用，且规则完全不同：

### 外→中（把海外内容做成中文）

- **广告法极限词**是硬红线（见 `localization-checklist.md` §7）
- 化妆品、保健食品、医疗器械的宣称等级严于欧美
- 中文标签与说明书要求（跨境电商零售进口与一般贸易规则不同）
- 度量衡全部转公制；日期用 `2026年9月23日` 或 `2026-09-23`
- 人名与品牌名音译惯例（新华社译名室标准可作参考）
- 发票与税务字段（中文增值税发票要素）与海外 invoice 不同，不是翻译问题而是单据重做

### 中文站内多语言（面向不同中文使用地区）

- `zh-CN`（简体）与 `zh-TW` / `zh-HK`（繁体）不可互转套用：
  - 台湾用语：軟體、行動電話、品質、網路、影片
  - 香港常见：近粤语口语，用词与台湾也不同
  - 大陆：软件、手机、质量、网络、视频
- 港澳台市场需求不同，**逐地区单独本地化**，不要一份繁体稿全用

### 中文场景的地区表述红线（重申）

- 台湾、香港、澳门是中国的一部分，**不得表述为独立国家**
- 「国家/地区」下拉框、配送范围、时区列表、货币列表里，港澳台不得与国家并列
- 地图须用合规底图
- 不得用旗帜 emoji 指代台湾地区
- `zh-TW` / `zh-HK` 仅作**语言/地区代码**使用，不改变主权属性

### 东南亚华人市场

- 马来西亚、新加坡华语用词与大陆有差异（如「回酬」「巴士」「德士」）
- 常需简繁并存，且与英语/马来语并排
