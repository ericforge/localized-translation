# 受管制品类标签、官方语言要求、中文市场场景

> **本文档只做「提示与定位」用途，不构成合规意见。** 规则必须按司法辖区、产品类别、载体、渠道和生效日期核验。具体条款号与限值会变动，执行前必须核对官方现行文本或咨询当地合规顾问。凡拿不准的，输出 `NOT_VERIFIED` 或 `BLOCKED`，不要赌。

本文件覆盖三块，都是「文字翻译对了但仍会被下架」的层面：

- A. 销售国**官方语言强制**要求
- B. 受管制品类的**强制标签内容**
- C. **中文市场与「外→中」**场景

---

## A. 销售国官方语言要求（按市场 × 品类 × 载体核验）

| 市场 | 要求 | 后果 |
| --- | --- | --- |
| 法国 | Loi Toubon 及具体产品法规可能要求法语；广告、商品页、标签、说明书的适用范围不同 | 按载体、品类和例外核验 |
| 加拿大 | 联邦和魁北克语言要求按产品、标签、渠道和省份判断；不应概括为所有内容强制双语 | 按产品法规和省级规则核验 |
| 瑞士 | 德语/法语/意大利语等按销售区域、产品和渠道判断 | 不能只按国家选择一种语言 |
| 德国 / 奥地利 | 说明书和安全信息是否必须德语取决于产品法规和载体 | 按产品类别核验 |
| 意大利 / 西班牙 / 荷兰 / 波兰 / 北欧 | 不能用“一般官方语言”替代具体法规要求 | 按市场、品类和文件类型核验 |
| 沙特 / 阿联酋 / 埃及 | 阿拉伯语要求取决于产品、标签、说明书和进口规则，英语是否并列也需单独确认 | 按主管机关和产品规则核验 |
| 韩国 | 许多受规管产品的标签、说明和广告有韩语要求，具体按产品法规、载体和渠道核验 | 可能下架或执法风险 |
| 日本 | 许多受规管产品的标签、说明和广告有日语要求；无线电的技適标识另行核验 | 可能下架或执法风险 |
| 巴西 | 许多产品的标签和说明需葡语版本，具体按品类和进口规则核验 | 可能影响清关或销售 |
| 中国 | 境内销售商品的标签与说明通常需中文；进口商品按适用中文标签规定核验 | 可能影响清关或销售 |

**操作规则**

1. 一句话结论：**「这产品要卖到哪个国家」决定了必须交付哪些语言的版本，而不是客户想要什么语言。**
2. 服务商说「只翻英语」时，主动提示上述强制要求。
3. 无法确认时，把「需目标国官方语言版本」写进「待确认」。

## B. 受管制品类的强制标签内容

### 食品 / 饮料（欧盟为代表）

- 过敏原**必须**突出标示（EU 14 类过敏原）
- 营养声明表格式与单位有法定排版要求
- 净含量、**保质期**、储存条件、生产商/进口商名称地址
- 成分表需按**含量降序**；配料名用当地法定名称
- **不属翻译范畴但必须提示**：这些内容的版式与内容需按目标市场重做，不只是把字翻过去

#### 保质期表述：一字之差，法律含义不同

**「保质期」不是可以直接替换的词**，各地术语的**法律含义**不同，写错会导致责任范围变化：

| 表述 | 含义 | 使用地 |
| --- | --- | --- |
| `Best before` | **品质**期限（过此日期仍可能安全可食） | 欧盟 |
| `Use by` | **安全**期限（过期不得销售/食用） | 欧盟 |
| `賞味期限` | 品质期限（对应 best before） | 日本 |
| `消費期限` | 安全期限（对应 use by） | 日本 |
| `Best if Used By` / `Sell By` / `Freeze By` | 美国体系，含义各不同（`Sell By` 是给零售商的，不是给消费者的） | 美国 |

处理规则：**不要用「保质期」一个词去对应以上全部**；先确认目标市场的法定术语，再选词。拿不准写进「待确认」。

### 化妆品 / 个护

- **成分名称不能一概不翻译** —— 应使用目标市场法定或认可的成分命名；保留 INCI 对照以便追溯。欧盟、美国、中国、日本的成分名称与标签语言规则分别核验
- 功效宣称受严格管制：「美白」「抗皱」「修复」等在中/日/韩/欧各有分级与禁用语
- 需标示：责任人名称地址、批号、开封后使用期（PAO）、注意事项
- 中文场景：《化妆品监督管理条例》下**不得宣称医疗作用**，特殊化妆品需注册

### 纺织品 / 服装 / 鞋类

- 纤维成分标示（含量百分比）为强制项，需按目标市场格式
- 洗护符号（洗涤、漂白、干燥、熨烫）为国际化符号，**图形不翻译**
- 欧盟对鞋类材质（鞋面/内里/鞋底）有标示要求
- 原产地标示

### 电子产品 / 电器

- 认证标志、符合性声明、测试报告、注册备案和标准名称不是同一概念。CE / UKCA / FCC / 技適 / KC / PSE / CCC / ANATEL / NOM 等必须按实际合格评定路径和持有文件使用，不得虚构
- 电压、频率、插头型（见 `localization-checklist.md` §2）
- 电池与电子废弃物的回收标识（WEEE 打叉垃圾桶、电池标识）
- 说明书中的安全警告不得删减

### 化学品 / 清洁剂 / 胶粘剂

- **CLP 法规**（欧盟）：危害象形图、信号词（Danger / Warning）、H/P 危险与防范说明句，均有法定措辞
- 这类文本**不能自由改写**，须用法规规定的标准语句；翻译质量取决于是否用了合规句式

### 儿童用品 / 玩具

- 年龄警示、成人监护提示、小零件窒息风险
- 欧盟 EN71、美国 ASTM F963 / CPSIA；标准、测试报告和 CPC（通常由制造商/进口商签发）必须分开核验
- 年龄分级表述按当地法规口径，不可自行降低

### 原产地与供应链溯源

- **消费者/海关原产地标示**：美国 19 CFR 134 等规则涉及进口商品原产国标示，必须区分消费者标签、海关原产地判断和平台展示
- **UFLPA**（维吾尔强迫劳动预防法）：属于供应链尽调、进口执法和证据留存问题，不应简化成一个标签翻译规则
- 原产地标示一旦写错属实质性违规，列为「待确认」高位项

## C. 中文市场与「外→中」场景

这份 skill 默认是「出海」视角，但反方向同样常用，且规则完全不同：

### 外→中（把海外内容做成中文）

- **广告法极限词**是硬红线（见 `localization-checklist.md` §7）
- 化妆品、保健食品、医疗器械的宣称等级严于欧美
- 中文标签与说明书要求（跨境电商零售进口与一般贸易规则不同）
- 度量衡全部转公制；日期用 `2026年9月23日` 或 `2026-09-23`
- 人名与品牌名音译惯例（新华社译名室标准可作参考）
- 发票与税务字段（中文增值税发票要素）与海外 invoice 不同，不是翻译问题而是单据重做

### 中文站内多语言（面向不同中文使用地区）

- `zh-CN`（简体）与 `zh-TW` / `zh-HK`（繁体）不可互转套用：
  - 台湾用语：軟體、行動電話、品質、網路、影片
  - 香港常见：近粤语口语，用词与台湾也不同
  - 大陆：软件、手机、质量、网络、视频
- 港澳台市场需求不同，**逐地区单独本地化**，不要一份繁体稿全用

### 中文场景的地区表述红线（重申）

- 台湾、香港、澳门是中国的一部分，**不得表述为独立国家**
- 「国家/地区」下拉框、配送范围、时区列表、货币列表里，港澳台不得与国家并列
- 地图须用合规底图
- 不得用旗帜 emoji 指代台湾地区
- `zh-TW` / `zh-HK` 仅作**语言/地区代码**使用，不改变主权属性

### 东南亚华人市场

- 马来西亚、新加坡华语用词与大陆有差异（如「回酬」「巴士」「德士」）
- 常需简繁并存，且与英语/马来语并排
